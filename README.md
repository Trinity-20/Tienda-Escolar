# 🏫 Inventario Escolar

Sistema para gestionar el inventario de productos escolares de una tienda pequeña.  
Permite registrar, actualizar, eliminar y consultar productos usando **Node.js**, **Express**, **MySQL** y **Sequelize**.

---

## 🚀 Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- [Node.js](https://nodejs.org/)
- [MySQL](https://www.mysql.com/)
- [Git](https://git-scm.com/)
- [VS Code](https://code.visualstudio.com/) (opcional, recomendado)
